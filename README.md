This project focuses on analyzing customer sentiment from Amazon product reviews. The goal is to extract insights from the reviews to understand customer opinions and improve product offerings.

**Project Workflow**
Data Collection: Gathered a dataset of Amazon product reviews.
Data Preprocessing: Cleaned and processed the reviews for sentiment analysis.
Sentiment Analysis: Applied natural language processing (NLP) techniques to classify the sentiment of each review as positive, negative, or neutral.
Visualization: The results were visualized using Tableau to provide clear insights.

**Tableau Dashboard**
Explore the interactive visualizations on Tableau: [Amazon Sentiment Analysis Dashboard](https://drive.google.com/drive/folders/1I5pfr6aXDLyISFpU2l_kUZ-gmzUPL_U0?usp=sharing)

**Key Insights**
Sentiment Distribution: Breakdown of positive, negative, and neutral reviews.
Product Performance: Sentiment comparison across different products.
Trend Analysis: Sentiment trends over time.
Technologies Used
Python: Data processing and sentiment analysis
Tableau: Visualization of the analysis results
Pandas & NLTK: Data manipulation and natural language processing
